# 账单助手 · 预制构件发货单合并工具

**当前版本：v1.3.1（2026-09-21）** — 工具每次更新都递增版本号，
打开 `账单合并工具/index.html` 后页面顶部标题栏即可看到版本；
完整更新记录见 [`账单合并工具/CHANGELOG.md`](账单合并工具/CHANGELOG.md)。

把每月不同项目、格式各异的 Excel 发货单 / 出库单，合并成一张规范的《发货明细汇总》，
并可进一步生成按楼栋分页的计价台账。

针对的真实场景：**每月换项目、各家单据格式都不一样、表头行位置不固定、列名写法五花八门**。
工具靠"语义识别 + 手动兜底"来适配，而不是要求你先把源表改成统一格式。

提供两种形态，按习惯二选一：

| 形态 | 适用 | 入口 |
|---|---|---|
| **本地网页工具**（推荐） | 双击即用，跨平台，功能最全（含台账生成） | `账单合并工具/index.html` |
| **VBA 宏** | 习惯在 Excel / WPS 里直接跑 | `发货单合并工具.bas` |

## 一、本地网页工具（推荐）

### 亮点

- **纯离线**：解析与合并全在你的浏览器里完成，文件不会上传到任何服务器。
- **自适应格式**：自动寻找表头行（会避开"修改打印时间…其他勿动"这类提示行），
  按同义词把源列映射到统一字段——`单构件砼体积（m³）`、`单块面积（m²）`、`m²面积`
  都能认到对应输出列。
- **识别表类型**：自动区分「发货单/出库单」（默认勾选）与「主表/其他」（默认不勾）。
- **跳过噪声行**：源表里的"合计 / 小计"行不会进入结果。
- **可增字段**：除标准 14 列外，支持自定义列（如"运输车号""客户姓名"）。
- **台账生成**：由合并结果直接生成按楼栋分页的计价台账，自动套单价、算含税金额。
- **当天单楼栋发货汇总 & 对账校核**：按"发货日期 × 楼栋 × 构件类型"汇总出库数据
  （车次/件数/方量/重量/面积/金额）并可导出——同天同楼栋发不同构件各占一行；
  支持把对账单汇总页的合计抄进来逐项核对（✔/✘），并自动比对台账合计与汇总合计。
- **文件夹导入**：可点「选择文件夹导入」或直接拖文件夹进来，自动递归读取
  子文件夹里的全部货单 Excel（适配"一天一个文件夹"的管理模式）。
- **导出附带原始货单（原格式含公式）**：三个导出（合并明细/台账/汇总）默认附上
  所有已勾选的原始货单，每张单一个工作表；原始单按**原格式整表复制**
  （字体/边框/颜色/合并单元格/列宽/行高/计算公式全部保留），
  等于把结果表和所有原始货单合并到一个工作簿，可直接转发给对方。
- **文件名 / 台账标题自动跟随**：默认是通用名（`发货明细汇总.xlsx`、`供货明细台账.xlsx`、
  标题"预制构件供货明细"），一旦导入文件就按导入文件名带出项目名——如
  `尚古大院2-1,2-2#发货单-供货明细台账.xlsx`、标题"尚古大院预制构件供货明细"，
  避免换项目时误用上一个项目的名字；自己手改过的名字不会被自动覆盖。

### 打开方式

1. 保持 `账单合并工具/` 里 5 个文件在一起：
   `index.html`（主界面）、`core.js`（合并核心逻辑）、`xlsx.full.min.js`（Excel 解析库）、
   `exceljs.min.js`（原格式复制库）、`使用说明.txt`（详细文档）；
   `demo.xlsx`（虚构示例数据）与 `CHANGELOG.md`（更新记录）可删。
2. **双击 `index.html`**，用 Chrome 或 Edge 打开。
   （别用 WPS / Office 打开它；若默认程序不对，右键 → 打开方式 → 选浏览器）
3. 想先用示例数据试一遍，在网址末尾加 `?demo=1` 后回车。

### 操作流程（6 步）

1. **选文件 / 选文件夹** — 点框或拖入（文件夹也行），可一次多份；「选择文件夹导入」
   会递归读取子文件夹。自动跳过输出文件（含"合并/汇总"命名）与 Excel 临时文件（`~$` 开头）。
2. **勾工作表** — 绿色标签为发货单/出库单，默认勾选；灰色为其他表，默认不勾。
   若表头行识别有误（黄色高亮），可在下拉框改行号。
3. **列映射** — 以第一张勾选的表为样例，自动对应输出列：`✔ 自动匹配到…` / `✘ 未自动找到`（手动指定或选择不输出）。
   发货时间有三种取法：① 从单据标题行/打印时间自动读日期；② 指定统一日期；③ 逐行取源列。
4. **合并 → 导出** — 显示总行数、各来源表贡献行数与前 20 行预览；确认后导出 `发货明细汇总.xlsx`。
5. **生成台账**（可选）— 按楼栋分页输出计价台账，支持账期分段（默认 26 日～次月 25 日）、
   日期偏移、日期范围过滤、自定义计价规则，每栋楼一个工作表。
6. **当天单楼栋发货汇总 & 对账校核**（可选）— 按"发货日期 × 楼栋 × 构件类型"汇总出库数据并导出；
   把对账单汇总页的合计填入"期望值"即可逐项核对（✔/✘ + 差额），并自动比对台账合计。

### 输出字段（标准 14 列）

```
序号 | 发货时间 | 构件编号 | 楼栋 | 楼层 | 构件类型 | 单块体积 | 单体质量 |
单块面积 | 板宽(mm) | 板长(mm) | 板厚(mm) | 砼标号 | 备注
```

### 环境要求

- 现代浏览器（Chrome / Edge），无需安装任何软件、无需联网。
- 仅支持 `.xlsx`；`.xls` 老格式请先在 Excel 里「另存为 .xlsx」。
- 唯一的联网情形：`xlsx.full.min.js` 缺失时才会尝试从公共 CDN 补下载该库。

## 二、VBA 宏

供习惯在 Excel / WPS 内操作的用户使用。选中文件夹后，自动把其中所有发货单 xlsx
合并为一张含"发货时间"列的汇总表。

**导入方式**：`Alt + F11` 打开 VBE → 文件 → 导入文件 → 选择 `发货单合并工具.bas` → 运行。

处理规则：

1. 跳过「构件编码 / PK板构件编码」等主表工作表；
2. 只处理行 1–8 含「项目名称 / 客户姓名 / 运输车号 / 出库总量」标记的发货单工作表；
3. 列按表头文本自动匹配（板宽/板长/板厚/砼标号顺序不同也能识别），缺失列留空；
4. 发货时间取标题行日期（如"成品出库单丨2026年3月8日…"），取不到时用"打印时间"单元格；
5. 自动跳过合计行与空行。

```
  ├─ 使用说明.txt             完整图文级使用说明
  ├─ CHANGELOG.md            更新记录（每个版本改了什么）
  └─ demo.xlsx               虚构示例数据
```

### 版本号约定

工具**每次更新都要递增版本号**：`v主.次.修`（修 bug 进"修"，加功能改默认行为进"次"，大改界面进"主"）。
版本号的唯一来源是 `账单合并工具/core.js` 的 `VERSION` / `BUILD_DATE`，
`index.html` 顶部标题栏、`使用说明.txt` 开头、`CHANGELOG.md` 第一条必须与之一致
（回归脚本 `test_version.js` 会自动校验，漏改会报错）。
提交信息也带版本号，如 `v1.1.1 fix: 修正台账日期偏移`。

> 说明：本仓库**只包含工具代码**。各项目的真实发货单 / 账单 Excel 与打包文件
> 已通过 `.gitignore` 排除，不会进入版本库。

## 四、常见问题

- **页面空白 / 点文件没反应** — 确认 3 个核心文件在同一文件夹，用浏览器刷新重开。
- **合并后行数与自己数的对不上** — 检查是否误勾了"主表/其他"的灰色表（如构件编码表，
  它是每个构件一行，勾了会多出大量行）。一般只勾发货单/出库单。
- **导出后某列为空** — 该列在映射里是"未自动找到"，手动指定源列后重新合并。
- **台账金额为 0 / 提示未匹配计价规则** — 该构件类型不在规则表内，添加一条计价规则即可
  （关键词写共有字样，如墙板填"墙板"）。
- **台账日期比发货单早/晚一天** — 在台账面板的「日期偏移(天)」填 `-1` / `+1`，无需改动原文件。
